Plantilla Base - Comercio Pequeño

Esta es la plantilla base para sitios web de comercios pequeños o emprendimientos personales.
Está pensada para ser clonada y adaptada a cualquier rubro sin tocar la estructura principal.

Estructura del proyecto

index.html → Página principal

css/styles.css → Estilos base reutilizables

js/main.js → Scripts futuros (actualmente vacío)

assets/img/ → Imágenes (logo, productos)

assets/icons/ → Íconos (SVG o PNG)

Las carpetas img e icons contienen archivos de ejemplo para que GitHub reconozca las carpetas.

Cómo usar:

Clonar este repositorio para un nuevo comercio.

Cambiar textos y colores según el negocio.

Subir imágenes propias a assets/img/.

Conectar a Netlify para deploy automático.

Buenas prácticas

No modificar nombres de clases CSS ni la estructura principal.

Mantener index.html limpio y organizado.

Usar main.js para scripts adicionales si es necesario.

Colores y tipografía pueden cambiarse en css/styles.css usando las variables de :root.
